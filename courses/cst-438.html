CST 438 · Summer 2026

Software Engineering

Course Description

Prepares students for large scale software development using software engineering principles. Covers software process, Agile planning, requirements, design, implementation, testing, code review, and deployment through a realistic team project.

What I Learned

This is the class that felt most like my actual job. Our team built a full stack gradebook and registrar system with a React frontend and two Spring Boot backends using Spring Data JPA and REST APIs. I learned Git branching and merging for real, reviewed teammates' pull requests the way Google structures code review, and wrote Agile user stories with acceptance criteria. Coming from QA, the testing units hit home: unit tests with Mockito, system tests with Selenium, and the testing pyramid. I also deployed a containerized Spring app to AWS ECS with an RDS database.

Evidence

Final project: a team gradebook and registrar app (React plus two Spring Boot services), including my instructor enrollments view with editable final grades and teammate PR reviews.
