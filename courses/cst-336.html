CST 336 · Fall 2025

Internet Programming

Course Description

Building dynamic web applications with HTML, CSS, JavaScript, Node.js, and Express, including server side rendering with templates, REST APIs, and working with databases.

What I Learned

This class connected the front end to the back end for me. I built Node and Express apps that render pages with EJS templates, handle routes and form data, and pull from APIs and databases. Seeing how a request travels from the browser to the server and back made it much easier to test web apps at work, and it gave me the foundation I later used to build MedLog and my capstone on Node and Express.
