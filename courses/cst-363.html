CST 363 · Summer 2025

Introduction to Database Systems

Course Description

Balanced coverage of database use and design with a focus on relational databases. Students design schemas, write SQL, access databases from code, and learn how query processing, indexing, transactions, and NoSQL systems work.

What I Learned

A database is not a fancy spreadsheet. It enforces integrity with constraints, keys, and relationships, and normalization keeps data from contradicting itself. I designed my own schema around something I actually care about (Pokemon cards and inventory), learned how views work as reusable virtual tables, and learned that a slow index is usually a query problem, not a broken index. Comparing MongoDB to MySQL showed me when a document store makes more sense than tables and rows. This is directly useful at work, where I query clinical data every day.

Evidence

Final project: a Pokemon card inventory schema, documented in my learning journal.
