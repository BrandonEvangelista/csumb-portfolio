CST 334 · Summer 2025

Operating Systems

Course Description

Use and design of modern operating systems with a focus on Linux. Covers the command line, shell scripting, and GNU tools, plus process management, CPU scheduling, memory management, concurrency, and file systems.

What I Learned

Computers stopped being a black box for me in this class. I hand calculated turnaround and response times for scheduling policies, learned how virtual addresses get translated to physical RAM and why that isolation protects memory, and wrote threaded code where I saw firsthand how shared data breaks without locks. Semaphores finally clicked when I realized a semaphore set to 1 is just a lock. I also compared programmed I/O with DMA to see how data actually moves between devices and memory.
