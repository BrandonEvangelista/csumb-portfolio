CST 311 · Fall 2025

Intro to Computer Networking

Course Description

How the internet actually works, layer by layer: application, transport, network, and link. Covers HTTP, DNS, TCP and UDP, IP addressing and subnetting, NAT, and routing, with hands on packet analysis and network programming.

What I Learned

Wireshark made the protocol stack real for me. I captured and read actual traffic for HTTP, DNS, TCP, IP, and NAT, and watched the TCP three way handshake happen packet by packet. I set up a Mininet virtual network to simulate hosts and links, wrote client and server programs with sockets, built a multi client TCP chat service, and worked through subnet addressing by hand. Today I use Postman to debug APIs at work, and this class is why I understand what is happening underneath the request.
