Software Design

Course Description

Builds the foundation for developing large scale software. Covers object oriented programming in Java, the software life cycle, requirements analysis, UML design, and building GUI applications as part of a team.

What I Learned

I came into this class after a year away from code and CodingBat humbled me fast. I learned that guessing and checking is not debugging. The biggest shift was planning before coding: on Project 1 our team of four built the UML diagram first and used it as the blueprint for the whole build. I also learned how much testing matters when a group project falls apart because the tests won't run.
