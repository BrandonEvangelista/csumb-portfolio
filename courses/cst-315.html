CST 315 · Summer 2026

Introduction to Cybersecurity

Taken in place of CST 383 on my Individual Learning Plan.

Course Description

Foundations of computer security: threats and attacks, cryptography, access control models, secure systems, network defense, and hands on offensive and defensive security tools.

What I Learned

This was the most hands on class of the program. I built a Kali Linux lab and worked through capture the flag exercises using Mininet and Amazon EC2 instances to hunt down hidden files. On the defensive side I wrote Splunk queries to analyze logs, read packet captures with tcpdump, and ran Snort intrusion detection against simulated attacks. I implemented security models in Python (Bell LaPadula, access control matrices, and attribute based access control), cracked a Caesar cipher, built a simple blockchain in Java, and exploited stack buffer overflows on picoCTF. Working at a medical device company, the access control and audit pieces connect directly to my day job.
